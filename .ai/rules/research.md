# Research records

Keep each report's raw source URLs, observation date and tool versions where relevant. Preserve the distinction between a published result, a local measurement and a proposed design. Mark an unchecked claim with the existing `Unverified:` prefix.

When adding a report, link it from `docs/research/README.md` and check that the relative link opens the intended file. For a local trial, record the input, commands, observed output and known gaps. Use public-safe names for private trial inputs.
